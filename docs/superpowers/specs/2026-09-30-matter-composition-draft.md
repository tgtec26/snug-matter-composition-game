## 1. 학습 핵심

**"물질은 입자로 이루어져 있다. 원소 기호·화학식·이온식은 그 입자의 종류와 개수를 적는 약속이고, 같은 원자라도 어떻게 모이느냐(원자 배열·분자·이온)에 따라 다른 물질이 된다."**

- **양성자수가 원소를 정한다** → 원자 조립에서 양성자를 하나 더 넣으면 다른 원소가 된다.
- **원자의 종류와 개수가 분자를 정한다** → 산소 원자 2개는 산소, 3개는 오존. 물 H₂O와 과산화 수소 H₂O₂는 다른 물질.
- **전자를 잃으면 양이온, 얻으면 음이온** → 이온식이 달라지고, 전류를 흘리면 반대 극으로 간다.
- 게임에서는 **조립한 것이 곧 화학식·이온식으로 써진다**. 암석 순환의 "선택 = 결과, 조작 = 특징"이 "무엇을 몇 개 넣었나 = 어떤 물질인가, 화학식은 그 기록"으로 이어진다.

## 2. 과학적 정확성 (반드시 유지)

교과서 용어·정의를 그대로 쓴다. 상세는 발췌 문서 2장.

| 개념 | 게임에서 지킬 것 |
|---|---|
| 원소·화합물 | 원소 = 한 가지 종류의 입자로 이루어진 물질, 화합물 = 서로 다른 종류의 입자로 이루어진 물질. 화합물은 성분 원소로 분해할 수 있고 성분 원소와 성질이 전혀 다름 |
| 원소 기호 | 첫 글자 대문자, 겹치면 중간 글자 소문자. 표기는 교과서(플루오린, 나트륨(소듐), 칼륨(포타슘), 메테인) |
| 화학식 | 원자 종류 = 원소 기호, 개수 = 오른쪽 아래 작은 숫자(1 생략). 금속처럼 원자가 연속 배열된 물질은 원소 기호만(Fe, Cu) |
| 원자 구조 | 원자핵((+) 양성자 + 전하 없는 중성자, 질량 대부분) + (-) 전자. 양성자수 = 전자 수 → 중성. **원자의 종류 = 양성자수** |
| 원자 모형 수치 | 수소 1·0·1, 탄소 6·6·6, 산소 8·8·8만 교과서에 있음. 다른 원소는 양성자수만 판정하고 **중성자수를 지어내지 않는다** |
| 주기율표 | 원자 번호(= 양성자수)순, 세로줄 족 18개, 가로줄 주기 7개. 같은 족 = 성질 비슷. 1족 리튬·나트륨·칼륨은 물과 활발히 반응해 기체 발생, 18족 헬륨·네온·아르곤은 상온 기체·잘 반응 안 함. 수소는 1족이지만 금속과 다름 |
| 분자 | 독립된 입자로 존재하여 물질의 성질을 나타내는 가장 작은 입자. 나누면 성질이 사라짐. 18족 원자 1개도 분자라 할 수 있음. 목록은 교과서 분자 12종만 |
| 이온 | 원자가 전자를 잃거나 얻어 전하를 띤 입자. 이온식은 오른쪽 위(1 생략). 양이온 "~ 이온", 음이온 "~화 이온"(산화·염화). 목록은 표 Ⅳ-1 + Na⁺·O²⁻·Mg²⁺만 |
| 이온의 이동 | 양이온 → (-)극, 음이온 → (+)극. 구리 이온 파란색, 과망가니즈산 이온 보라색. 극을 바꾸면 반대로 |
| 용어 | 전자 껍질·전자 배치·옥텟 X, 이온 결합·공유 결합 X("결합하여"만), 전기 분해 X("물 분해"), 알칼리 금속·비활성 기체 X("1족 원소"·"18족 원소"), 불소·메탄 X |

- 분자 모형은 공 모양 원자를 붙인 그림으로만 표현하고, 결합 각도·모양·결합 종류를 설명하지 않는다.
- 이온 공방에서는 교과서 이온만 주문서로 준다. 임의 이온(Na²⁺ 등)은 만들 수 없게 한다.

## 3. 게임 한 줄 요약

주인공은 **입자 공작소의 견습 공작사** (물질 분리 공방의 견습생이 "입자 현미경" 속으로 들어간 설정 — 캐릭터 재사용 가능). 공작소에는 방이 다섯 개 있다. **원자 조립기**에서 양성자·중성자·전자로 원자를 만들고, **주기율표 광장**에 그 원소를 자리에 놓고, **분자 조립소**에서 원자를 붙여 분자를 만들면 화학식이 자동으로 써지고, **이온 공방**에서 전자를 주고받아 이온을 만든 뒤 **이온 이동 실험대**에서 전류를 흘려 어느 극으로 가는지 확인한다. 만든 것은 모두 **원소·분자·이온 도감**에 등록되고, 마지막 주문은 "염화 나트륨 수용액에 전류 흘리기"처럼 다섯 방을 다 거쳐야 완성된다.

## 4. 구조 (공작소 지도 + 주문서, `WorkshopScene`)

이 단원의 과학 구조는 **위계**다: 원자(양성자수) → 원자 배열 · 분자 · 이온 → 물질(원소·화합물). 그래서 지도는 아래에서 위로 올라가는 **다섯 개의 방**이고, 주문서가 어느 방을 거칠지 정한다.

```
[주문판: 공작소 주인 "입자 박사"]
   주문 1 "물 한 방울"      : 원자 조립(H, O) → 분자 조립(H₂O) → 원소/화합물 갈림길
   주문 2 "공기 한 줌"      : 분자 조립(N₂, O₂, CO₂) → 갈림길 3번
   주문 3 "오존층"          : 분자 조립(O₂ vs O₃) → "같은 원자, 다른 개수 = 다른 물질"
   주문 4 "소금 한 알"      : 원자 조립(Na, Cl) → 이온 공방(Na⁺, Cl⁻) → 배열
   주문 5 "약수터의 비밀"   : 이온 이동 실험대 (구리 이온·과망가니즈산 이온)
   주문 0 튜토리얼 "수소·탄소·산소" : 원자 조립기 + 주기율표 광장

[방] 원자 조립기 ─▶ 주기율표 광장 ─▶ 분자 조립소 ─▶ 이온 공방 ─▶ 이온 이동 실험대
       (원소 카드)    (족·주기 확인)    (화학식 자동)   (이온식 자동)   (극 선택 = 방향)
```

- **주문 하나 = 물질 하나.** 주문서에 "구성 성분"만 적혀 있고(예: 수소, 산소), 어떤 입자로 만들지는 방에서 조작한 결과로 정해진다.
- **갈림길**은 두 곳: ① 분자 조립 뒤 "이 물질은 원소? 화합물?" ② 이온 공방에서 "전자를 잃을까, 얻을까?" (교과서 이온만 정답이 되도록 주문서에 원소가 정해져 있음: 나트륨은 잃고, 염소는 얻는다).
- 잘못 만들면 교과서 근거로 막힌다: 전자 수 ≠ 양성자수 → "전기적으로 중성이 아니에요 — 이온 공방으로 가면 돼요", 산소 원자 3개 → "그건 산소가 아니라 오존이에요" (틀림이 아니라 **다른 물질**로 등록), 양성자 하나 더 → "탄소가 아니라 질소가 됐어요".
- **원소 카드 놀이**(141쪽)는 주기율표 광장의 **보너스 놀이**: 이름 카드 위 말, 기호 카드 뒤집기. 교과서 규칙 그대로 1인 시간제.

## 5. 미니게임 (방별)

| 방 | 미니게임 (가칭) | 조작 | 결과가 결정하는 것 |
|---|---|---|---|
| 원자 조립기 (144~145쪽) | **원자 만들기** | 양성자·중성자를 원자핵 자리에, 전자를 주위에 드래그. 원자핵에 "+N" 표시가 커짐 | **양성자수 = 원소** (1 수소 … 20 칼슘). 전자 수가 같아야 중성 → 원소 카드 등록. 수소·탄소·산소는 중성자수까지 교과서 표대로 |
| 주기율표 광장 (146~149쪽) | **자리 찾기** | 만든 원소 카드를 1~20번 빈칸에 드래그. 세로줄·가로줄 하이라이트 | 원자 번호순 배치. 1족에 놓으면 물에 넣는 연출(기체 발생), 18족은 무반응 연출. 카드에 족·주기 기록 |
| 분자 조립소 (142~143, 155쪽) | **원자 붙이기** | 원자 블록을 작업대에 놓고 서로 붙임. 붙일 때마다 위에 **화학식이 실시간으로 써짐** (H → H₂ → H₂O) | 원자 종류·개수 = 분자. 주문과 맞으면 등록, 다른 교과서 분자면 "다른 물질" 등록(O₃, H₂O₂). 목록 밖은 붙지 않음 |
| 이온 공방 (156~157쪽) | **전자 주고받기** | 원자에서 전자를 빼내거나(양이온) 넣기(음이온). 이온식이 오른쪽 위에 써지고 이름이 읽힘 | 잃음/얻음 + 개수 = 이온식(Na⁺, Cl⁻, O²⁻, Mg²⁺, Cu²⁺…). 염화 나트륨은 Na⁺·Cl⁻를 격자에 번갈아 배열해 완성 |
| 이온 이동 실험대 (158~159쪽) | **전류 흘리기** | 거름종이를 질산 칼륨 수용액으로 적시기(스포이트), 전선을 (+)(-)에 연결, 전압 12 V, 색 이온 떨어뜨리기 | 파란 구리 이온이 (-)극으로, 보라 과망가니즈산 이온이 (+)극으로. 극을 바꾸면 반대로. 예측 맞히기(어느 극?) = 별 |

- 미니게임 1개 45~75초. 조작은 암석 순환 광물 실험대(드래그·드롭·문지르기)와 물질 분리 공방 실험대 방식.
- 보너스: **원소 카드 놀이**(141쪽), **물 분해**(150쪽, 건전지 세워 넣기 → 두 전극 기체 → "물은 화합물") 연출.

## 6. 진행·보상

- **도감 3장**: 원소 카드 20(원자 번호 1~20, 기호·이름·족·주기·상온 상태), 분자 도감 12(화학식·구성 원자·원소/화합물), 이온 도감 11(이온식·이름·잃거나 얻은 전자 수·이동 극). 원자 배열 물질 카드(금·구리·철·알루미늄·흑연·다이아몬드)는 갈림길 정답으로 획득.
- **한 판 = 튜토리얼 + 주문 5개, 10분 내외 (최대 15분).** 방 5개를 한 번씩 이상 거침.
- 별점: 조립 정확도(불필요한 입자·시간) + 갈림길 첫 시도 + 주문 후 퀴즈 1문항(발췌 3장 35문항).
- 엔딩: 오늘 만든 물질의 "입자 지도"(원자 → 분자/이온 → 물질) 요약, 도감 진행률.

## 7. 기술 (암석 순환·물질 분리 공방 구조 재사용)

- 테스트: 양성자수 → 원소, 전자 수 불일치 판정, O₂/O₃·H₂O/H₂O₂ 구분, 이온식 문자열, 이동 극, 주문 완료 순서, JSON 검증.
- 그림: 공작소 배경 1, 방 배경 5, NPC(입자 박사) 1, 주인공(견습생 재사용), 입자 아이콘(양성자·중성자·전자·원자 20종 공), 장치(주기율표 판, 작업대, 거름종이 실험대) — SVG 우선.

## 10. 설계 확정 기록

### 10-1. 세계관·범위 (2026-09-30 승인)
- 주인공은 입자 공작소의 견습 공작사. 공작소 주인 NPC "입자 박사"의 주문서를 받아 방 4개를 거친다.
- 방은 원자 조립기 → 주기율표 광장 → 분자 조립소 → 이온 공방. 이온 이동 실험은 미니게임 없이 퀴즈·도감 카드 문구로만 다루고, 실험대는 이후 추가 후보.
- 원소는 원자 번호 1~20. 분자·이온도 이 범위 안의 교과서 목록만(분자 12종, 단일 원자 이온 7종). 여러 원자로 된 이온과 구리 이온은 자료실 카드.
- 마지막 주문은 "바닷물 한 방울"(159쪽 확인 2: 염화 이온·나트륨 이온·마그네슘 이온 + 물 분자)로 방 4개를 모두 거친다.
- 나머지 항목(4~6)은 스펙 v1(`2026-09-30-matter-composition-design.md`)의 제안값으로 진행하고, 검토 시 확정한다.
