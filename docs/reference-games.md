# 레퍼런스 게임 조사 (입자 공작소)

지침 9번 "레퍼런스 게임 조사 필수"에 따른 기록이다.

- 작성: 2026-09-30. **회고 조사**다. 이 게임은 조사 전에 스펙 승인과 구현이 끝났다. 그래서 "스펙에 반영"이 아니라 **이미 닮은 점**과 **아직 빌려 오지 않은 점**으로 나눠 적는다.
- 출처와 한계: 웹 검색 요약만 썼다. PhET 공식 사이트는 이 세션의 네트워크에서 열리지 않아(접속 차단) 공식 설명을 직접 읽지 못했고, 교육 자료 사이트·상점 페이지·공략 사이트의 설명에 나온 내용만 적었다. 직접 플레이해서 확인한 것은 없다. 행마다 확인 수준을 적었다.
- "아직 빌려 오지 않은 점"은 제안일 뿐 결정이 아니다. 교과서 범위를 벗어나는 것은 채택하지 않았다.

## 1. PhET 원자 만들기 (Build an Atom)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 양성자·중성자·전자를 더하고 빼면서 원소, 전하, 질량이 어떻게 정해지는지 본다. 원자 화면, 기호 화면, 게임 화면이 있고 게임은 한 판에 5문제다. 첫 게임은 입자 구성을 보고 원소를 맞히는 문제다 |
| 확인 수준 | 교육 자료 사이트 요약 (RSC 교육 기사, 위스콘신 교육청 자료 목록). 공식 안내서 링크는 검색에 나왔으나 열지 못함 |
| 이 게임에서 닮은 점 | 원자 조립기(`AtomBuilderOverlay`: 양성자·중성자·전자를 끌어 놓고 **실시간으로 원소 이름**이 바뀜), 주기율표 칸 배치, 이온 공방(전자를 끌어내고 넣으면 이온식과 이름이 바뀜) |
| 아직 빌리지 않은 점 | 질량 표시와 기호 읽기 화면. **채택하지 않는다**: 교과서에 중성자수는 수소·탄소·산소만 있어(AGENTS.md) 질량을 계산하는 조작은 교과서 밖으로 나간다 |

## 2. PhET 분자 만들기 (Build a Molecule)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 주어진 원자 세트로 분자를 만든다. 화면은 단일·여러 개·놀이터로 나뉜다. 컬렉션 상자마다 분자 3~5개를 채워 가는 구조다. 만든 분자를 3차원으로 돌려 볼 수 있다 |
| 확인 수준 | 교육 자료 사이트 요약 (spoken-tutorial, ComPADRE). 공식 페이지 미확인 |
| 이 게임에서 닮은 점 | 분자 조립소(`MoleculeBenchOverlay`: 원자 공을 끌어 붙이고 **실시간 화학식**), 교과서 목록 밖 조합은 튕김, 교과서의 다른 분자를 만들면 보너스 카드(놀이터 성격), 도감(`particle-dex-v1`)에 쌓이는 수집 구조 |
| 아직 빌리지 않은 점 | 분자를 돌려 보는 3차원 보기. **채택하지 않는다**: 교과서는 분자 모양·결합 각도를 다루지 않고 AGENTS.md도 "공을 붙인 그림으로만, 모양·각도를 말하지 않는다"로 정했다. 돌려 보면 각도를 주장하는 그림이 된다 |

## 3. Little Alchemy 2

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 흙·물·공기·불에서 시작해 아이템 두 개를 **끌어서 겹치면** 새 아이템이 팝업으로 나타난다. 만든 것과 조합법이 도감에 남고, 힌트 버튼이 만들 수 있는 것 하나를 알려 준다. 시행착오로 발견하는 구조 |
| 확인 수준 | **낮음.** 검색 결과가 공략·안내 사이트 모음이어서 개발사 설명을 확인하지 못했다. 널리 알려진 규칙과 일치하는 내용만 적었다 |
| 이 게임에서 닮은 점 | 원자를 끌어 붙여 새 물질이 생기는 분자 조립, 새로 얻은 것이 도감 카드로 남음, 목록 밖 조합은 튕겨 나옴 |
| 아직 빌리지 않은 점 | **힌트 장치.** 한참 조작이 없을 때 대상이나 칸이 깜빡이는 비언어적 힌트(지침 3번 "조작 장면은 비언어적 안내")가 있는지 확인하지 않았다. 없다면 후속 후보다 |

## 4. Cooking Mama (닌텐도 DS)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 요리 한 단계가 곧 10초 안팎의 미니게임이다. 재료 잡기, 끌어서 달걀 깨기, 원을 그려 뭉치기 같은 **터치 동작이 요리 행동과 닮았다**. 짧은 미니게임의 연속이라 규칙 설명이 거의 필요 없다 |
| 확인 수준 | 위키·리뷰 사이트 요약 (StrategyWiki, Games Asylum). 직접 플레이 안 함 |
| 이 게임에서 닮은 점 | 방 4개를 짧은 조립 조작으로 이어 가는 구조, 끌어 놓기 중심 조작 |
| 아직 빌리지 않은 점 | 단계마다 **즉시** 주는 짧은 평가 연출. 지금은 방을 끝내면 별로 모아 준다 |

## 5. 정리

- 이 게임은 PhET 원자·분자 만들기와 같은 문법(입자를 끌어 놓으면 이름·식이 실시간으로 바뀜)에 Little Alchemy류 수집(도감·보너스 카드)을 얹은 구조로 읽힌다.
- 빌려 오지 않은 것 중 PhET의 질량 표시와 3차원 보기는 교과서 범위 때문에 **의도적으로 제외**한다. 후속 후보는 힌트 깜빡임과 단계 끝 즉시 평가 정도다 (결정 아님).
